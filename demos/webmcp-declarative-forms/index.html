Your forms are already tools

Two ordinary HTML forms with a few extra attributes (toolname, tooldescription, toolparamdescription, toolautosubmit). An agent fills them from their markup alone; a human sees normal forms. JavaScript only comes in to answer the agent without navigating. Companion demo for the blog post — see README.md.

Page script skipped (?nojs). The forms behave as if JavaScript were disabled: the passenger stepper stays a plain number input, and submitting navigates to submitted.html with a normal GET. For the real thing, disable JavaScript in DevTools. Back to the full demo.
